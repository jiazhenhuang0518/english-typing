输入法版：平时打字顺便学英语

把手机、电脑的输入法换成 Rime + 雾凇拼音，聊天、写文档时候选词后面直接显示英文：

1. 苹果〔apple〕2. 🍎3. 评过4. 平果
1. 学习〔learn; study〕2. 学系3. 学〔learn; study〕

反过来打英文单词也行：打 apple 会出现 apple〔苹果〕。

Rime、雾凇拼音是什么？（点开）

Rime（中州韵）是一个开源的输入法“发动机”，各平台都有：Mac 叫鼠须管，Windows 叫小狼毫，安卓叫同文，iPhone 叫仓输入法。可以把它想成一台能自己改装的车。

雾凇拼音是装在 Rime 上的一套现成的拼音词库和设置，打字手感接近搜狗、微信输入法。

这个页面给的东西 = 雾凇拼音 + 我们加的「英文注释」，英文来自开源词典 CC-CEDICT。

📱 iPhone / iPad（仓输入法）
  1. App Store 装 仓输入法（免费，自带雾凇拼音）。
  2. 系统「设置 → 通用 → 键盘 → 键盘 → 添加新键盘」选「仓输入法」，再点它打开「允许完全访问」（英文注释用到的小脚本需要它）。
  3. 用 Safari 点下面按钮下载补丁包，下载完点地址栏左边的 ⬇️ → 点文件 → 左下角「分享」⬆️ → 选「仓输入法」。
  4. 打开仓输入法 App → 首页「RIME」→「重新部署」，等它转完（第一次几十秒）。
  5. 聊天时长按键盘左下角 🌐 切到仓输入法，打 pingguo 看看。

🤖 安卓（同文输入法）
  1. 下载安装 同文输入法 APK（近几年的手机都选这个；装不上再试 其他版本）。
  2. 打开同文，按提示授予「文件访问」权限，并在系统里启用它。
  3. 下载下面的完整包，用手机自带「文件管理」解压，把解压出来的所有文件放进手机存储根目录的 rime 文件夹（没有就新建；里面原有的同名文件选覆盖）。
  4. 同文 App →「部署」，等它跑完（第一次要 1～3 分钟）。
  5. 切到同文键盘打 pingguo 试试；如果不是雾凇拼音，在同文 App 的「方案」里选「雾凇拼音」。

💻 Mac（鼠须管）
  1. 打开「终端」（启动台搜 “终端”），粘贴下面这行，回车：
curl -fsSL https://jiazhenhuang0518.github.io/english-typing/rime/install-mac.sh | bash
  1. 中途要输入开机密码（输的时候屏幕上不显示，正常），这是在装鼠须管。
  2. 「系统设置 → 键盘 → 文字输入 → 编辑… → 左下角 +」→ 简体中文 → 鼠须管 → 添加。找不到就注销重新登录一次。

脚本会把原来的 ~/Library/Rime 改名备份，不会删。

🪟 Windows（小狼毫）
  1. 右键「开始」按钮 →「终端」或「Windows PowerShell」。
  2. 粘贴下面这行（很长，用复制按钮），回车：
[Net.ServicePointManager]::SecurityProtocol='Tls12'; iex ([Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://jiazhenhuang0518.github.io/english-typing/rime/install-windows.ps1')))
  1. 弹出小狼毫安装窗口就一路「下一步」，装完脚本会自动放配置、部署。
  2. 按 Win + 空格 切到小狼毫，打 pingguo 试试。

开关英文注释

Mac / Windows打字时按 Ctrl + `（数字 1 左边的键）或 F4，选「英文 / 无英」
手机默认一直开着；仓输入法、同文的键盘菜单里一般有「方案选单 / 开关」可以切

每次重新打开输入法默认是开着的。

老实说
  • 输入法里只有单词的英文，不会翻译整句。整句翻译、跟打、复习还是用 网页 App。
  • 输入法打过的词不会自动进词本，和网页 App 的进度不互通。看到想学的词，去网页 App 查一下就会进词本。
  • 英文是从词典里按规则自动挑的前一两个意思，大部分准，少数会怪（比如很书面、或一个字有很多意思时）。一句话的整体候选（比如“我在学习”）通常没有注释，只有词典里有的词才有。
  • iPhone 上输入密码时系统会强制换回苹果键盘，这是 iOS 的规定，所有第三方输入法都一样。
  • Windows 脚本我没有在 Windows 电脑上实际跑过（这边只有 Mac）；出问题时可以手动做：装 小狼毫 → 把完整包解压到 %APPDATA%\Rime → 右键托盘里的「中」→「重新部署」。
  • 仓输入法自带的雾凇拼音版本由仓自己决定；如果打字没出英文，可以在仓输入法的「文件管理」里把上面安卓用的完整包整个导入（会替换掉仓自带的那套）。
