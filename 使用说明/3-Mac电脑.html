Mac 电脑

这台 Mac 上配置已经放好了，只差装鼠须管（要你输开机密码，我没法替你输）。

一、网页 App

  1. 用 Chrome 打开 https://jiazhenhuang0518.github.io/english-typing/
  2. 地址栏右边有个「安装」图标（电脑 + 箭头）→ 安装。以后从启动台 / 程序坞打开。Safari 也行：菜单「文件 → 添加到程序坞」。
  3. 建议在电脑上先把「我的 → 手机电脑同步」连好，再给手机配对。

手机电脑同步进度（可选，做一次就行）

  1. 先在电脑上做：网页 App →「我的」→「手机电脑同步」，按页面上的 3 步去 GitHub 生成一个令牌（只勾 gist），粘回来点「连接」。
  2. 连好后在电脑上点「给手机/另一台电脑配对」，屏幕上出现二维码。
  3. 手机打开相机扫这个二维码 → 点弹出的链接 → 自动连上。

令牌相当于一把只能开 GitHub 小文件（Gist）的钥匙，只存在你自己设备的浏览器里。

二、输入法（鼠须管 + 雾凇拼音 + 英文注释）

第 1 步：双击安装

  1. 打开 使用说明/安装包/Mac/，双击「双击安装输入法.command」。会弹出一个「终端」黑窗口。
  2. 提示输入密码时输入开机密码，回车。输的时候屏幕上什么都不显示，是正常的。
  3. 等它显示「装好了」，按任意键关掉窗口。
如果双击提示「无法打开」：右键这个文件 →「打开」→ 再点「打开」。

它做了三件事：装鼠须管（官方签名安装包）→ 把原来的 ~/Library/Rime 改名备份 → 放入新配置并部署。

第 2 步：在系统里添加鼠须管

  1. 「系统设置」→「键盘」→「文字输入」那一栏点「编辑…」。
  2. 左下角「+」→ 左边选「简体中文」→ 右边选「鼠须管」→「添加」。
  3. 列表里找不到鼠须管：屏幕左上角 →「退出登录」，重新登录后再找。

第 3 步：用起来

  • 按 Ctrl + 空格（或键盘上的 🌐 / 地球键）切到鼠须管。
  • 打 pingguo，看到
    苹果〔apple〕　🍎　评过　平果
    就成功了。
  • 中英文切换：按一下 Shift。
  • 开关英文注释：打字时按 Ctrl + `（数字 1 左边的键）→ 选「英文 / 无英」。

出问题怎么办

  • 没有英文 / 候选不对：屏幕右上角菜单栏的输入法图标 → 鼠须管 →「重新部署」，等十几秒。
  • 想恢复原来的配置：~/Library/ 里有 Rime.bak-日期 文件夹，把现在的 Rime 删掉，备份改回 Rime，再「重新部署」。
  • 不想要了：在「文字输入」里把鼠须管删掉（选中按「−」）就不会再出现。
  • 以后要更新词库：重新运行一次「双击安装输入法.command」就行（会自动备份旧的）。
