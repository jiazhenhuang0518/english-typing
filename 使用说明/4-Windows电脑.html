Windows 电脑

两种方法：拷文件夹过去双击（不用等下载），或者联网粘一行命令。

一、网页 App

  1. 用 Edge 或 Chrome 打开 https://jiazhenhuang0518.github.io/english-typing/
  2. 地址栏右边的「安装」图标（或右上角 ⋯ →「应用」→「将此站点作为应用安装」）。以后从开始菜单打开。

手机电脑同步进度（可选，做一次就行）

  1. 先在电脑上做：网页 App →「我的」→「手机电脑同步」，按页面上的 3 步去 GitHub 生成一个令牌（只勾 gist），粘回来点「连接」。
  2. 连好后在电脑上点「给手机/另一台电脑配对」，屏幕上出现二维码。
  3. 手机打开相机扫这个二维码 → 点弹出的链接 → 自动连上。

令牌相当于一把只能开 GitHub 小文件（Gist）的钥匙，只存在你自己设备的浏览器里。

二、输入法（小狼毫 + 雾凇拼音 + 英文注释）

方法 A：拷文件夹双击（推荐）
  1. 把 使用说明/安装包/Windows/ 整个文件夹拷到 Windows 电脑上（U 盘、网盘、微信文件传输助手都行，4 个文件要在一起）。
  2. 双击「双击安装输入法.bat」。
  3. 弹出蓝色「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
  4. 弹出小狼毫安装窗口：一路「下一步 / 安装」；问简体还是繁体选简体；问要不要管理员权限选「是」。
  5. 装完黑窗口会继续放配置、部署，显示「装好了」后按任意键关掉。
方法 B：联网一行命令
  1. 右键「开始」按钮 →「终端」或「Windows PowerShell」。
  2. 复制下面这一整行，粘进去，回车：
[Net.ServicePointManager]::SecurityProtocol='Tls12'; iex ([Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://jiazhenhuang0518.github.io/english-typing/rime/install-windows.ps1')))

网页里的输入法安装页有「复制命令」按钮，更方便。

用起来

  • 按 Win + 空格 切到「小狼毫」（或点任务栏右下角的输入法图标选）。
  • 打 pingguo，看到
    苹果〔apple〕　🍎　评过　平果
    就成功了。
  • 中英文切换：按一下 Shift。
  • 开关英文注释：打字时按 Ctrl + ` 或 F4 → 选「英文 / 无英」。

出问题怎么办

Windows 脚本我只在 Mac 上写好、没在 Windows 电脑上真跑过。脚本报错就用下面的手动方法，一样的效果。

手动安装（脚本不行时）

  1. 双击 weasel-0.17.4.0-installer.exe 装好小狼毫。
  2. 按 Win + R，输入 %APPDATA%\Rime 回车，打开配置文件夹（打不开就先新建）。里面原来的东西可以先整个拷走备份。
  3. 把 rime-ice-english-full.zip 右键「全部解压缩」到这个文件夹里（文件直接在 Rime 里，别多套一层）。
  4. 右下角任务栏的小狼毫图标（「中」字）右键 →「重新部署」。
  • 没有英文：右键「中」→「重新部署」；还不行检查 %APPDATA%\Rime 里能不能直接看到 english_hint.dict.yaml。
  • 恢复原来的配置：脚本把旧的改名成 Rime.bak-日期，在 %APPDATA% 里，改回来再重新部署。
