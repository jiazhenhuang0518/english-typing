iPhone / iPad

先装网页 App（2 分钟），再装输入法（10 分钟）。

一、网页 App

  1. 用 iPhone 相机扫下面左边的二维码，用 Safari 打开（别用微信里打开）。
  2. 点底部「分享」⬆️ → 往下找「添加到主屏幕」→ 添加。桌面上会出现「打字学英语」图标，以后从图标打开。
网页 App

手机电脑同步进度（可选，做一次就行）

  1. 先在电脑上做：网页 App →「我的」→「手机电脑同步」，按页面上的 3 步去 GitHub 生成一个令牌（只勾 gist），粘回来点「连接」。
  2. 连好后在电脑上点「给手机/另一台电脑配对」，屏幕上出现二维码。
  3. 手机打开相机扫这个二维码 → 点弹出的链接 → 自动连上。

令牌相当于一把只能开 GitHub 小文件（Gist）的钥匙，只存在你自己设备的浏览器里。

二、输入法（仓输入法 + 英文注释）

第 1 步：装仓输入法

App Store 搜「仓输入法」（免费），或者扫码打开安装页里的链接。它自带雾凇拼音。

第 2 步：在系统里打开它

  1. 「设置」→「通用」→「键盘」→「键盘」→「添加新键盘…」→ 选「仓输入法」。
  2. 回到键盘列表，点「仓输入法」→ 打开「允许完全访问」。这步必须做：不开的话键盘读不到你导入的补丁，能打中文但不会有英文。

第 3 步：把补丁包给仓输入法（两种方法选一种）

方法 A：扫码下载（简单）
  1. 用相机扫下面的二维码，用 Safari 打开安装页 → 展开「iPhone」→ 点「下载 iPhone 补丁包」→ 弹窗点「下载」。
  2. 别从桌面上「打字学英语」图标里进安装页去点，那里面 iPhone 不让下载文件；也别在微信里打开。点了没反应就用方法 B。
  3. 下载完点地址栏左边的 ⬇️（或「文件」App →「下载」）→ 点开 english-hint-overlay.zip 所在位置 → 长按这个文件 →「共享」→ 选「仓输入法」。
输入法安装页
方法 B：从 Mac 隔空投送（AirDrop）
  1. Mac 上打开 使用说明/安装包/iPhone/，右键 english-hint-overlay.zip →「共享」→「隔空投送」→ 选你的 iPhone。
  2. iPhone 收到后选用「仓输入法」打开；如果直接存进了「文件」，就在「文件」里长按它 →「共享」→「仓输入法」。

补丁只有 4 个文件，不会覆盖仓输入法自带的雾凇拼音和你的其他设置。

第 4 步：部署

打开仓输入法 App → 首页「RIME」→「重新部署」，等它转完（第一次几十秒）。部署就是把词库编译一遍，改了配置都要做一次。

第 5 步：用起来

  1. 随便打开一个能打字的地方（备忘录、微信）。
  2. 长按键盘左下角 🌐 → 选「仓输入法」。
  3. 打 pingguo，看到
    苹果〔apple〕　🍎　评过　平果
    就成功了。

出问题怎么办

  • 打字没有英文：① 确认第 2 步「允许完全访问」开了 ② 仓输入法 App 里再「重新部署」一次 ③ 还不行，就把 安装包/安卓/rime-ice-english-full.zip（完整包）也按第 3 步的方法给仓输入法，再部署。完整包会覆盖仓自带的雾凇拼音配置。
  • 方案列表里的「英文注释数据」：是给雾凇拼音查英文用的词典，不是打字方案，不用勾、也别在键盘里切到它；打字用「雾凇拼音」，排在「已选输入方案」第一个。
  • 输密码时键盘变回苹果键盘：iOS 规定，所有第三方输入法都这样，正常。
  • 候选很少 / 打不出字：刚部署完键盘有时要等几秒，收起键盘再打开。
  • 想换回原来的输入法：长按 🌐 选别的键盘就行，仓输入法留着不影响。
